Manrope is the existing UI/body typeface. This unmodified variable font is
bundled to avoid Next16.2.10 Google-font loader failures on font URLs that do not end
in a recognized filename extension. The existing400–700 weights, CSS variable and swap
display remain. Fraunces and IBM Plex Mono keep their existing configuration.
